## 1. 产品概述

封山巡护移动 App 是一款专为护林员在封山禁入期执行巡山任务而设计的移动端应用。应用以离线优先、户外场景为核心设计理念，帮助护林员高效完成巡护路线、隐患上报、人员联络、物资管理等日常工作，保障封山期间森林资源安全。

- **目标用户**：护林员、巡护队长、值班室调度人员
- **核心价值**：提升封山巡护效率，确保巡护过程可追溯，隐患信息及时上报，人员安全实时掌控

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 护林员 | 管理员分配账号 | 领取任务、巡护打卡、隐患上报、查看同伴位置 |
| 巡护队长 | 管理员分配账号 | 护林员全部权限 + 任务分配、紧急通知发布、物资审批 |
| 值班室调度 | 管理员分配账号 | 接收上报、查看全员位置、一键呼叫、通知下发 |

### 2.2 功能模块

1. **巡护首页**：紧急通知横幅、今日任务概览、快捷功能入口、实时状态看板
2. **路线任务**：领取巡护路线、封控边界地图、路线节点到达打卡、路线进度追踪
3. **隐患上报**：拍照取证、语音备注、上报偷采偷猎、上报火源隐患、标记临时封路
4. **人员联络**：同伴位置地图、一键呼叫值班室、紧急求助按钮、群组消息
5. **物资点**：物资领取清单、领取登记、劝返人数登记、物资库存查询
6. **离线包**：离线地图下载、离线保存轨迹、网络状态检测、恢复网络后自动补传
7. **统计记录**：个人巡护里程、巡护时间统计、按日期导出记录、历史记录查询

## 3. 核心流程

### 3.1 巡护任务流程

护林员打开应用后，在首页查看紧急通知和今日任务，进入路线任务页面领取巡护路线，沿路线行进并在各节点打卡，途中发现隐患立即拍照取证并上报，遇到人员误入进行劝返登记，完成路线后返回查看统计。

```mermaid
flowchart TD
    "打开应用" --> "查看紧急通知"
    "查看紧急通知" --> "领取巡护路线"
    "领取巡护路线" --> "沿路线行进"
    "沿路线行进" --> "到达节点打卡"
    "到达节点打卡" --> "发现隐患?"
    "发现隐患?" --> "是" --> "拍照取证并上报"
    "发现隐患?" --> "否" --> "继续行进"
    "拍照取证并上报" --> "继续行进"
    "继续行进" --> "路线完成?"
    "路线完成?" --> "否" --> "沿路线行进"
    "路线完成?" --> "是" --> "查看统计记录"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深森林绿 (#1B4332) + 橄榄绿 (#2D6A4F)，传达自然、稳重、专业的护林氛围
- **辅助色**：琥珀警示色 (#D4A017) 用于紧急通知和隐患标识，珊瑚红 (#E63946) 用于紧急求助
- **按钮风格**：大尺寸圆角按钮，最低 44px 触控区域，适合戴手套操作
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular，尺寸偏大确保户外可读
- **布局风格**：移动端优先，底部 Tab 导航，卡片式内容展示
- **图标风格**：线性图标 + 填充图标双状态，线条粗实，户外阳光下清晰可辨

### 4.3 响应式设计

- **移动端优先**：所有页面以 375px 宽度为基准设计，最大宽度 480px
- **触控优化**：所有可交互元素最小触控区域 44x44px，按钮间距不低于 8px
- **户外可读**：高对比度配色，字号不小于 14px，关键信息 18px 以上
- **横屏适配**：地图类页面支持横屏查看，布局自动切换为左右分栏

### 4.4 动效设计

- **页面切换**：左右滑动过渡，与底部导航联动
- **打卡反馈**：成功打卡时播放涟漪扩散动画 + 震动反馈
- **紧急通知**：横幅脉冲闪烁 + 铃声提醒
- **数据同步**：上传动画（箭头上移 + 进度环）
